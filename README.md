# ערכת נושא – לוח עברי

אפליקציה נפרדת עבור `com.lionscribe.hebdate` (לוח עברי 8.90), שאינה משנה את קובץ ה-APK המקורי.

## מה היא עושה
- 7 ערכות צבע: כהה, כחול לילה, יער, סגול, שקיעה, זהב וללא גוון.
- שכבת תצוגה שקופה מעל לוח עברי באמצעות Accessibility Overlay.
- פתיחת לוח עברי מתוך האפליקציה.
- בחירת הערכה נשמרת במכשיר.

## התקנה והפעלה
1. מתקינים את ה-APK של ערכת הנושא.
2. פותחים אותה ובוחרים ערכה.
3. לוחצים על "הפעל הרשאת ערכת נושא".
4. בהגדרות הנגישות מפעילים את השירות "ערכת נושא – לוח עברי".
5. חוזרים לאפליקציה ולוחצים "פתח לוח עברי".

העיצוב הוא שכבת תצוגה חיצונית. הוא לא משנה את ה-APK המקורי, ולכן ניתן להסיר את ערכת הנושא בלי להסיר את לוח עברי.
